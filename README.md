

## GPT - Agents


This project is about an internal corporate agent that is designed to extract information from Marketo tool documentation. The project offers two different agent implementations:

 - **Agent 1: Microsoft Azure OpenAI Service (GPT-3.5 Turbo Model)** (main.py)

This agent is designed with the Azure OpenAI Service and uses the GPT-3.5 Turbo model for natural language understanding and generation. It is designed to interpret and reply to questions about Marketo documentation, providing automated support for a variety of use cases inside the organization.

- **Agent 2: Langchain-Based Agent with OpenAI API and Pinecone Vector Database** (main_dev.py).


The second agent is built with the Langchain library and uses the OpenAI API for language processing. It also leverages the Pinecone Vector Database to manage and query vectorized data, allowing for quick and effective information retrieval from the Marketo documentation.


Each agent is designed to provide adaptable and scalable solutions for increasing productivity through automated interactions with Marketo resources, according to specific infrastructure and technology requirements.
